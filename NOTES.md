# Notes

## RP-K100 vs RP-K105

The [RK-T32 Manual](https://archive.org/details/manual_RKT32_OM_PANASONIC_EN/),
page 38, says:

* RP-K100 is RS232 serial and and Centronics Parallel
* RP-K105 is Centronics Parallel only

Also, the same manual page mentions buffer memory in RP-K100. This makes be
believe that RP-K105 was the cheaper model, with no RS232 serial and no buffer
memory.

## RP-K* vs KX-R60

Main difference: the RP-K* models use a DE-9/DB-9 connector, and the KX-R60 uses
a MiniDIN-8. The same connector as round Macintosh serial ports, but it is NOT
pin-compatible with serial ports.

Pin 5 of the Typewriter connector supplies +12V DC to power the KX-R60.

KX-R60 only has Centronics Parallel, no RS232 Serial.
